## 소개

중앙대학교 사진학과를 졸업하고 AI 엔지니어링으로 전환한 **조윤서(Jay Cho)**의 개인 포트폴리오 사이트입니다.  
예술적 감수성과 기술을 연결하는 작업들을 담았습니다.

### 주요 이력

- 🎓 중앙대학교 사진학과 졸업 (B.F.A. Photography)
- 🤖 AI 엔지니어 부트캠프 수강 · 인턴 경험
- 🏆 아모레퍼시픽 AI 챌린지 **특별상** — AI 에이전트 CRM 메시지 자동화 생성
- 📈 그로스마케팅 부트캠프 수강
- 🎨 예술경영지원센터 아트비즈니스챌린지 수료 · 창업경진대회 **본선 진출**

## 기술 스택

| 구분 | 사용 기술 |
|------|-----------|
| Framework | Next.js 16 (App Router) |
| UI | React 19, TypeScript |
| Styling | Tailwind CSS v4 |
| Font | Noto Sans KR, Geist |

---

## 페이지 구성

```
/
├── Hero        — 이름·태그라인·CTA
├── About       — 소개 및 배경
├── Career      — 경력·교육 타임라인
├── Awards      — 수상 및 성과
├── Skills      — AI/마케팅/크리에이티브/비즈니스 역량
└── Footer      — 연락처·GitHub 링크
```

---

## 로컬 실행

```bash
# 의존성 설치
npm install

# 개발 서버 시작
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 접속.
